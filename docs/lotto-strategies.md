# LOTTO LAB V2 전략 계산

전략은 모두 1~45에서 중복 없는 6개를 선택하고 오름차순으로 정렬합니다. 과거 데이터는 **대상 회차보다 앞선 완료 회차**만 사용합니다. 추첨 결과를 등록하면 다음 회차의 Frequency, Recency, LUCID MODEL 계산에 반영됩니다. RANDOM은 과거 데이터에 영향을 받지 않습니다.

| 전략        | 현재 구현                                                                                                                              |
| ----------- | -------------------------------------------------------------------------------------------------------------------------------------- |
| RANDOM      | 1~45 배열을 부분 Fisher–Yates 방식으로 섞어 여섯 숫자를 선택합니다.                                                                    |
| FREQUENCY   | 전체 과거 당첨번호의 출현 횟수에 1의 기본 가중치를 더해, 중복 없이 가중 추출합니다. 낮은 빈도의 번호에도 선택 가능성을 남깁니다.       |
| RECENCY     | 최근 30회에 `exp(-age / 10)` 가중치를 부여합니다. 가장 최근 회차의 `age`는 0입니다. 번호마다 1의 기본 가중치를 둡니다.                 |
| BALANCED    | 무작위 조합 80개 중 홀짝 3:3, 1~22/23~45 분포, 10단위 구간 수, 합계 138 근처, 연속·끝자리 과다를 기준으로 가장 높은 점수를 선택합니다. |
| LUCID MODEL | 전체 빈도, 최근 30회, 마지막 출현 후 경과 회차를 결합한 가중치로 조합 40개를 만들고 BALANCED 점수가 가장 높은 조합을 선택합니다.       |

가중치와 점수는 실험을 위한 휴리스틱입니다. 결과를 평가하기 전의 고정된 계산 규칙으로 사용하며, 장기 기록을 통해 비교합니다. 통계 패턴이나 한 전략이 독립적인 추첨에서 당첨 확률을 높인다는 의미는 아닙니다. 새로운 공식을 도입한다면 기존 기록의 전략 버전도 별도로 구분해야 합니다.
